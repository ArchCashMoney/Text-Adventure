CS202 Final Project

**Compile:** `g++ -std=c++17 main.cpp Game.cpp -o dungeon`
**Run:** `./dungeon`

Navigate the dungeon using directional commands (`north`, `south`, `east`, `west` or `n/s/e/w`), pick up items with `take [item]`, and fight enemies with `attack`. Your goal is to find the iron key in the Ancient Library, unlock the Stone Gate, defeat the Dragon, and reach the Treasury to win. Type `help` in-game for the full command list.
